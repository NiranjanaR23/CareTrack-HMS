# Hospital Management System

A DBMS project implementation based on the supplied PPT.

## Stack
- Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
- Backend: PHP 8+
- Database: MySQL

## Modules
1. Patient Management
2. QR-based patient medical record access
3. Appointment Scheduling
4. Digital Token / Queue
5. Medical Records
6. Billing
7. Reports
8. Role-based Login

## Run
1. Install XAMPP/WAMP.
2. Copy this folder into `htdocs`.
3. Start Apache and MySQL.
4. Open phpMyAdmin and import `database.sql`.
5. Edit `config/db.php` if your MySQL username/password differs.
6. Open `http://localhost/hospital_management_system/login.php`.

Demo accounts:
- Admin: admin / admin123
- Doctor: doctor / doctor123
- Receptionist: reception / reception123

This is a college-project MVP. For real healthcare use, add HTTPS, stronger authentication, audit logging, encryption and proper authorization.
